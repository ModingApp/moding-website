# 모딩 상세페이지 비주얼 파이프라인

## 입력 모드

1. 실물상품 그대로 사용
   - 실제 판매상품 이미지를 업로드한다.
   - 상품 자체는 AI로 변형하지 않는다.
   - 배경제거/누끼, 색감·명암, 자연스러운 그림자만 허용한다.

2. 상품사진 + 조리사진
   - 두 이미지를 별도 레이어로 유지한다.
   - 템플릿이 상품/조리 비율과 위치만 자동 배치한다.

3. 상품사진만 있음
   - 상품 레이어는 원본을 보존한다.
   - 조리예시는 별도 생성 레이어로 추가한다.
   - 조리예시 생성은 실제 상품의 성격·용도를 참고하되 상품 패키지나 원물 자체를 재생성하지 않는다.

## 기본 원칙

- PRODUCT 레이어는 보호 레이어다.
- COOKING 레이어는 교체/재생성 가능한 연출 레이어다.
- CUTOUT은 PRODUCT 레이어의 배경 제거 상태를 뜻한다.
- 전체 페이지를 다시 생성하지 않는다.
- 수정은 선택 레이어 단위로 수행한다.
