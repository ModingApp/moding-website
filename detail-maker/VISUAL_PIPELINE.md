# 모딩 상세페이지 제작기 V3

## 제작 흐름

1. 입력 화면에서 상품정보를 한 번만 입력한다.
2. 실제 상품사진과 선택사항인 조리사진을 업로드한다.
3. 메인·상세 1·상세 2·스티커를 동시에 구성한다.
4. 결과 화면에서 장별 문구와 장식 레이어를 수정한다.
5. 현재 장 PNG 또는 전체 ZIP을 2048 × 2048 규격으로 출력한다.

## 상품사진 보호

- 상품의 형태·포장·라벨·문구를 다시 생성하지 않는다.
- 흰 배경 제거는 사진 가장자리와 연결된 중성 흰색 영역에만 적용한다.
- 배경 제거가 적합하지 않은 사진은 원본으로 전환할 수 있다.
- 상품사진과 조리사진은 각각 정해진 템플릿 프레임 안에 고정 배치한다.
- 모든 이미지 프레임은 클리핑되어 캔버스 밖이나 다른 정보 영역을 침범하지 않는다.

## 화면 구성

- 입력 화면과 결과 편집 화면을 분리한다.
- 데스크톱에서는 페이지 목록·캔버스·요소 편집기를 한 화면에 배치한다.
- 1180px 이하에서는 페이지 목록을 상단 가로 탭으로 전환하고 요소 편집기를 캔버스 아래로 이동한다.
- 720px 이하에서는 상단 작업 버튼을 가로 스크롤로 제공해 화면 밖으로 잘리지 않도록 한다.

## 저장과 출력

- JSON에는 입력정보, 원본·배경정리 상품사진, 조리사진, 장별 레이어 수정값을 저장한다.
- 현재 장은 단일 PNG로 출력한다.
- 전체 결과는 JSZip이 준비된 경우 ZIP 한 개로 출력하고, 준비되지 않으면 장별 PNG로 출력한다.
