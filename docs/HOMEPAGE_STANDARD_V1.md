## 화면과 동작

- 메인: 제목 → 애니메이션 → 짧은 설명 → 공통 다운로드. 다운로드 아래 판매자 입점 보조 링크는 두지 않습니다. 메인 아래 별도 입점 영역의 버튼 문구는 판매자 입점을 유지하고 https://seller.moding.app으로 직접 연결합니다.
- 홈페이지 장면은 discovery, connection, delivery, pantry, favorite, receipt, menu 7종입니다. assets/js/homepage-scenes.js의 그림·제목·설명을 함께 유지합니다.
- 처음 진입/새로고침/심볼 클릭에서 무작위 선택합니다. 창 크기 변경·상담 열기/닫기는 선택을 바꾸지 않습니다. 같은 그림의 재생 루프와 장면 선택은 별개입니다.
- 별도 박스→식당 연출은 메인 아래 입점 영역에 둡니다.
- 흰색 헤더의 기존 로고와 한글 메뉴를 사용합니다. 1:1은 로고가 포함된 둥근 고정 버튼입니다.
- 규격은 assets/css/site-presentation.css의 --moding-* 역할별 변수에서 변경합니다. 문서 본문·FAQ 그림·일반 버튼·다운로드 버튼을 같은 크기로 덮어쓰지 않습니다.
- 기본 웹/좁은 화면 제목 56/36px, 설명 22/16px, 카드 제목 22/18px, 카드 본문 18/16px, 보조 안내 15/14px입니다. 821~1100px에서는 제목 44px·설명 18px·카드 제목 20px·본문 18px를 사용합니다. 헤더 84/72px, 일반 버튼 높이 56px, 주요 문의·다운로드 버튼 72/64px, 아이콘 조작 영역 44px 이상입니다. 작은 높이에서는 내용 스크롤을 허용합니다.
- 헤더는 페이지당 하나이며 모바일에서도 로고와 메뉴 조작 버튼은 같은 행입니다. 메뉴 닫기는 흰 바탕에서 초록색으로 표시합니다.
- 고정 문의 버튼은 64/60px, 내부 로고 26/24px, 글자 14px·700입니다. 일반 행동 버튼은 16px·700, 주요 문의·다운로드 문구는 18/16px, 다운로드 보조 글자는 14px입니다. 상담 뒤로·닫기·첨부도 최소 44px 조작 영역을 확보합니다.
- 회사정보는 footer-company 역할로 12px를 유지합니다. 문의·이동 버튼이 회사정보와 법적 링크를 가리지 않도록 하단 공간을 확보합니다. 창 밖 내용을 overflow:hidden으로 감춰 검수를 통과시키지 않습니다.
- 모션 줄이기를 지원하고 가용 창 너비로 배치합니다. 특정 미출시 기기 이름을 검수 증거로 사용하지 않습니다.

## 이동 동작 보존

- 홈 → 모딩 소개 → 브랜드 → 이용 안내 → 판매자 입점 → 자주 묻는 질문의 기존 좌우 링크·터치 스와이프를 유지합니다. 세로 이동은 각 페이지의 장면 사이 스크롤이며 다른 URL로 임의 이동시키지 않습니다.
- 메인을 포함한 안내 페이지는 CSS 화면 단위 스냅을 유지합니다. 긴 장면은 내용 전체를 읽을 수 있어야 하며, FAQ의 특정 답변 이동은 스냅보다 우선합니다.
- 메인 아래 화살표와 맨 위에서 당겨 새로고침을 유지합니다. 7종 장면의 무작위 선택 규칙은 바꾸지 않습니다.
- 좌우 화살표는 1:1 버튼과 겹치지 않습니다. 메뉴·상담이 열리면 화살표도 비활성화합니다. 화면 가장자리의 브라우저 제스처, 입력·버튼 조작, 세로 스크롤은 가로 이동으로 처리하지 않습니다.
- 배포 전 test/browser-navigation.mjs로 실제 휠·스와이프·화살표·FAQ·상담·뒤로가기를 검사합니다. 화면 크기 검사만으로 이동 기능 통과를 선언하지 않습니다.

## 공통 비율과 간격 · 2026-10-12 보완

- 공통 수치의 소유자는 `assets/css/site-presentation.css`입니다. `site-roles.js`에서 페이지 요소를 역할에 매핑합니다. 카드 제목/본문/보조 안내도 반드시 매핑하고 페이지별 작은 높이 규칙으로 글씨를 축소하지 않습니다.
- 대상별 큰 카드 제목은 32/26px로 구분합니다. 모바일에서 브랜드 네임의 긴 설명은 한 열로 전환하고 창 높이가 낮아져도 본문을 숨기지 않습니다.
- 콘텐츠 최대 폭 1280px, 웹 좌우 여백 32px, 좁은 화면 20px. 두 열 배치는 같은 폭의 열과 56px 간격을 사용하고 821~1100px은 32px, 820px 이하는 한 열로 전환합니다.
- 제목→설명 24/16px, 설명→카드 그룹 32/24px, 카드 사이 16/12px, 카드 내부 24/20px, 카드 제목→본문 8px. 같은 역할은 페이지와 무관하게 같은 규칙을 따릅니다.
- 주요 문의·다운로드 기준 폭 248/232px. 같은 행동 그룹은 같은 폭과 높이를 사용합니다. 상담 로고 30px, 고정 문의 로고는 기존 26/24px입니다. 인라인 문의 버튼은 `30px / 문구 / 30px` 대칭 열을 사용해 로고와 무관하게 문구 자체가 버튼 중심에 오도록 합니다. FAQ 마지막 장면은 상담과 다운로드 두 버튼만 두고, 600px 이하에서는 한 열로 배치합니다.
- 메인은 제목의 실제 줄 수로 높이를 계산합니다. 제목·그림·설명·다운로드를 하나의 중심축에 모읍니다. 7종 그림의 전체 움직임 범위와 안전 여백을 사용하며, 원본 그림 좌표·문구·재생 시간은 바꾸지 않습니다.
- FAQ 추가 안내는 “추가 문의는 1:1 상담으로 문의해 주세요.”입니다. 이메일 문의 버튼은 제거합니다. 법적 회사정보 이메일은 유지합니다.
- 검수에는 1260×1230(사용자 캡처와 유사한 긴 창)과 1440×900의 100% 배율을 포함합니다. 공통 글씨 크기 적용, 같은 그룹 버튼 비율, 메인 수직 중심/중심축/실제 그림 범위를 자동 확인하고 모든 마케팅 장면을 눈으로 비교합니다.

- 카드 제목은 700, 일반 본문·보조 설명은 400, 주요 설명은 600으로 구분합니다. 서비스 프레임은 `data-moding-frame`, 격자는 `data-moding-role="grid"`로 독립 적용합니다. 작은 화면에서 읽는 내용은 숨기지 않으며 닫힌 FAQ·메뉴·상담의 상태 제어는 유지합니다.
- 상세 제작기·판매자 신청·관리자 초기 로그인·제안서는 독립 웹 화면 규격을 사용합니다. UI 확대를 생성 결과 캔버스나 인증·신청 로직에 적용하지 않습니다.

- 너비 1100px 이하 또는 높이 800px 이하에서는 하단 96px를 문의·좌우 이동 조작에 사용하고, 읽는 영역은 그 위에서 스크롤합니다. 저높이 PC의 홍보 제목/설명은 44/18px로 조정하고 메인 그림은 최소 180px 영역을 확보합니다. 본문 18/16px와 보조 15/14px는 유지합니다.
