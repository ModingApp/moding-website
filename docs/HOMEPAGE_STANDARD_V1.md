- 처음 진입/새로고침/심볼 클릭에서 무작위 선택합니다. 창 크기 변경·상담 열기/닫기는 선택을 바꾸지 않습니다. 같은 그림의 재생 루프와 장면 선택은 별개입니다.

- 흰색 헤더의 기존 로고와 한글 메뉴를 사용합니다. 1:1은 로고가 포함된 둥근 고정 버튼입니다.

## 이동 동작 보존

- 홈 → 모딩 소개 → 브랜드 → 이용 안내 → 판매자 입점 → 자주 묻는 질문의 기존 좌우 링크·터치 스와이프를 유지합니다. 세로 이동은 각 페이지의 장면 사이 스크롤이며 다른 URL로 임의 이동시키지 않습니다.
- 메인을 포함한 안내 페이지는 CSS 화면 단위 스냅을 유지합니다. 긴 장면은 내용 전체를 읽을 수 있어야 하며, FAQ의 특정 답변 이동은 스냅보다 우선합니다.
- 메인 아래 화살표와 맨 위에서 당겨 새로고침을 유지합니다. 7종 장면의 무작위 선택 규칙은 바꾸지 않습니다.
- 좌우 화살표는 1:1 버튼과 겹치지 않습니다. 메뉴·상담이 열리면 화살표도 비활성화합니다. 화면 가장자리의 브라우저 제스처, 입력·버튼 조작, 세로 스크롤은 가로 이동으로 처리하지 않습니다.
- 배포 전 test/browser-navigation.mjs로 실제 휠·스와이프·화살표·FAQ·상담·뒤로가기를 검사합니다. 화면 크기 검사만으로 이동 기능 통과를 선언하지 않습니다.
