삭제 안내

모딩 채널 스튜디오에 연결한 Threads 계정의 인증 토큰과 연결 정보를 아래 방법으로 삭제할 수 있습니다.

스튜디오에서 직접 연결 해제

  1. 모딩 채널 스튜디오에 로그인합니다.
  2. 회사 작업공간에서 SNS 계정 연결 메뉴를 엽니다.
  3. 연결된 Threads 계정에서 연결 해제를 선택합니다.

연결을 해제하면 해당 Threads 연결에 저장된 OAuth 액세스 토큰과 계정 연결 정보가 삭제됩니다.

이메일로 삭제 요청

스튜디오에 접속할 수 없는 경우 partner@moding.app으로 작업공간명과 연결된 Threads 사용자명을 보내주세요. 요청자의 작업공간 권한을 확인한 뒤 삭제를 처리합니다.

비밀번호, 인증번호, 액세스 토큰 또는 앱 시크릿 코드는 이메일이나 문의 내용에 포함하지 마세요.

삭제 범위

  • 모딩 채널 스튜디오에 저장된 Threads 인증 토큰
  • Threads 사용자 ID·사용자명과 계정 연결 상태
  • 해당 연결을 유지하기 위해 저장한 권한 및 토큰 만료 정보

이미 Threads에 공개된 게시물은 Threads 계정에 남아 있으므로 Threads 앱 또는 웹에서 별도로 삭제해야 합니다.

개인정보 처리 안내

처리 항목과 목적에 관한 자세한 내용은 모딩 채널 스튜디오 개인정보 처리 안내에서 확인할 수 있습니다.
